>[!info] Compactly Supported
>A given function $\rho$ is **compactly supported** if it is zero everywhere outside some bounded interval. Can think of all the "mass" of the function of being in some interval $[a,b]$ (although doesn't have to be a real interval).

>[!info] Operator norm
>The operator norm of a matrix $M$ is defined as 
>$$||M|| = \sup_{||v||=1}|Mv|$$
>Basically, what this answers is "what is the longest length that $M$ can stretch a vector $v$", which we can see is defined to be a unit vector.
